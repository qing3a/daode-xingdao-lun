# 新版-行道论

> 对《道德经》的逐章再阐释——一套以生存与发展为基点的系统学说。
> 作者：青山（个人作品，非学术翻译，不依从市面上的通解）

全文：[道德经-行道论.md](道德经-行道论.md)

## 这是什么

《道德经》成书两千余年，通行解读多从玄理、修身、权术入手。本书不走这条路。

**行道论是作者自己的一套完整概念系统**：用统一的词汇逐章重写《道德经》（每章"行道版"），并把每一句标注在结构中的角色上——它是现象、是建模、是策略、还是评论。目的是让古老文本变成一个**可检验、可实践**的体系，能用来理解组织、市场、治理、产品与日常选择，而不只是供人赞叹的玄言。

---

## 核心概念系统

全书的概念地基在《前言》里三句话讲完，后面八十章全部由此展开：

1. **体、力、能、得、失**
   万物在不断聚散中构建主体结构。存续下来能被观察到的称为**体**，维持主体存续的要素称为**力**，体与力的结合称为**能**，生成体与力的过程是**得**，反之是**失**。

2. **得与失的过程，就是生存与发展的过程。**
   生存与发展是每个主体的天然需求。为了避免冲突，人们在保障生存的同时，根据迫切程度轮流发展——但需求和欲望、内部和外部、局部与整体之间的博弈远未停止。

3. **人是劳动和价值判断的主体。**
   两者在实事上构建了以需求和欲望为目标的结构关系。为此，行道论完善了**天地、玄衡、有无、得施、善与**等概念，道与德、得与施、失与事、有与无由此徐徐展开。

## 本书的关键定义（作者的理解）

行道论对核心字词的界定与通行读法不同，先在开篇立好，后文一以贯之：

| 概念 | 行道论的定义 |
|------|--------------|
| **道** | 言说、路、周期、非人实体、场景、权力。"什么是道？别挡我的道。"道**不只是人的生存策略，而是包含人、事、物的整体策略** |
| **无** | 结构状态：贫穷、接纳、承载、需求。容器。 |
| **有** | 结构状态：富有、施加、实践、供给、利用。 |
| **得 / 施** | 得——拉拢与威慑；施——给予。得施构成全书的主要张力。 |
| **无为** | 接纳、支撑，认可并支撑所有人的生存发展需求。**社会的本质是协作，而不是感受和对错。** |
| **德** | 对"得"的规训（得法德）。玄德：摒弃好恶，自然而德。 |
| **玄** | 此消彼长、动态均衡。"众妙之门：此消彼长是四象的开始。万灵之缘：每次均衡都是人群的聚散。" |
| **道冲** | 器皿：平台、货币、秩序、信仰、话语权等。形状是倒三角——上宽以容，下尖以承。 |
| **天道** | 动态均衡供需两侧："不贵难得之货——保障物价、补贴创新、调控供给结构。这是通篇的题眼，是对天地人的迎合和争取。" |
| **相** | 标签、学科、视角、身份、角色、结构、轮动。 |
| **三宝** | 慈、俭、不敢为天下先——本质是：不自、守敛、善与。 |

一些贯穿全书的对照关系：

- **有无**有四种读法：状态（长期需求与短期需求、存量与增量、全球与本土）、视角（容器与内容、供应链与规则）、价值（计量与分配）、结构（劳动供需——组织者与生产者，货币与商品）。
- **内道外道**：无为与不贵，一个是对内的道，一个是对外的道。
- **两大斗争实体**：需求与欲望同出而异名，都能承载和组织。
- **四大**：道大、天大、地大、人亦大。**道法中间**——认可天地，支撑中间，自然太宏观，要降一格。
- **柔弱胜刚强**："坚的形，激发了水的势，成就了水流的能。"强大处下，柔弱处上。
- **天之道**：损有余而补不足（再分配）；人之道：损不足以奉有余。

行道论还把古老概念落回现代场景：做产品要"辅助用户发展才更长久"；治理要"承认存量，支持增量，服务无量"；"大者宜为下"——产业、服务、供给、基础设施是转化漏斗的高度；"将以愚之"——如游戏开发，创新玩法只能提高转化，精准的数值策略才是七日留存的关键。

## 读法

每一章由这几部分组成：

- **行道版**：把该章原文改写成现代系统语言（这是全书的骨架）。
- **【现象】【建模】【策略】【评论】**：给每一句标注结构角色——
  - 【现象】：世界中可观察到的状况
  - 【建模】：现象背后的结构与生成模式
  - 【策略】：如何行动
  - 【评论】：对本章的反思，常在此解开原文的"悖论"
- **注释**：逐条界定本章关键词（道、德、有、无、得、施……）。
- **系统动态图**：把本章的核心力量压成一行（如"生、贵、贱""和、光、尘"）。
- **说明 / 备注 / 专题**：必要的补充与专题展开（如第二章"有无"四读）。

## 阅读建议

1. **先读前言。** 三句话给出整套概念系统（体、力、能、得、失），其余八十章皆由此展开。
2. **一次读一章。** 每章自成一体：先读行道版，再看注释；需要时展开说明、备注与专题。
3. **带着"这用在哪里？"读。** 行道论面向实践——每一句都可以问：它对组织、市场、团队、产品、日常选择意味着什么？
